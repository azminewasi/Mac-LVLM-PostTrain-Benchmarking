Token-level and speed analytics: what post-training does to inference cost

November 19, 2026 · Qwen3.5-0.8B with LoRA · Apple M5 MacBook Pro, 16 GB · 4 runs (still running)

Training changes what the model writes, and what it writes decides what inference costs. This page measures it per token: how long the answers are, how many tokens each correct answer costs, and how fast the MacBook produces them.

Headline. The untrained model writes about 392 tokens per answer (1006 tokens for each correct one). After training, SFT gentle writes 8 tokens per answer and 9 per correct answer, so the same question costs 111x fewer generated tokens.
